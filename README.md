# 🎮 JavaScript XO Game

**JavaScript XO Game** is a **Tic-Tac-Toe** game built with vanilla **HTML, CSS, and JavaScript**. You play as **X** against a **computer opponent (O)** on a 3x3 grid — the computer blocks your winning moves, takes its own winning moves when available, and otherwise plays the center or a random open cell.

## 🚀 Features

- ✅ **Responsive Design** – The game board adapts to all screen sizes.
- 🎮 **Player vs Computer** – You play **X**, the computer plays **O** with basic blocking/winning logic.
- 🏆 **Winner Highlight** – The winning combination is highlighted in green with a scale animation.
- 🤝 **Draw Detection** – Displays a message when the board fills up with no winner.
- 🔄 **Play Again Button** – Appears at game end to instantly reset the board.

## 🛠️ Installation

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Iqbolshoh/javascript-xo-game.git
cd javascript-xo-game
```

### 2️⃣ Open `index.html`
Simply open the `index.html` file in any modern web browser to start playing — no build step or server required.
